# 🏏 Hand Cricket Command-Line Game

A lightweight, two-player terminal-based Python implementation of the classic childhood **Hand Cricket** game.

---

## 🚀 Features
- **Turn-based gameplay:** Two innings where each player gets a turn to bat and bowl.
- **Instant Out Detection:** Innings automatically end when batter and bowler match inputs.
- **Modular Codebase:** Game logic separated into pure functional units for automated testing.
- **Automated Tests:** Includes `pytest` test suite covering turn mechanics and score evaluation.
